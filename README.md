# Web Portofolio Laravel

Dinara Aulia Safina

## 📄 Deskripsi

Website portofolio sederhana yang dibangun menggunakan Laravel untuk memahami alur MVC, routing, controller, dan Blade templating.

## 📁 Struktur Utama

-   `routes/web.php` → Routing
-   `app/Http/Controllers/DashboardController.php` → Controller
-   `resources/views/layout/` → Layout Blade (main, header, footer)
-   `resources/views/page/` → Halaman statis (about, portofolio, interest, contact)
